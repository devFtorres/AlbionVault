# AlbionVault

**Albion Online Stats & Guild Management Platform**

AlbionVault is a comprehensive management tool for Albion Online players, designed to help solo players, friend groups, and guilds track their stats, manage resources, and improve their gameplay.

## 🚀 Features (Planned)

- 📊 Personal stats tracking
- 👥 Guild management
- 📈 Performance analytics
- 💰 Economy tracking
- 🗺️ Territory management

## 🛠️ Tech Stack

- Next.js 15
- React 19
- Tailwind CSS
- (More to be added)

## 💻 Getting Started
```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
